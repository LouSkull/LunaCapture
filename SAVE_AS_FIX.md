# Region Save As

- Region Editor `Save as` opens the native Windows save dialog.
- The user chooses folder, filename, PNG or JPEG.
- The current screenshot directory and format are used as defaults.
- Cancel returns to LunaShot without writing a file.
- Copy remains independent and does not open a dialog.
- Active-window click capture keeps its instant default-save workflow.
- Visual application version remains 1.0.0.0.

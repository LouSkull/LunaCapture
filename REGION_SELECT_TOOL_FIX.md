# Persistent Select Tool

- **Select** is now the first item in the Region Editor toolbar.
- Select remains active after a selection is completed.
- Every drag creates a new selection, including drags that begin inside the current selection.
- Starting a new selection clears annotations and redo history attached to the previous region.
- The selection tool changes only when Arrow, Rectangle, Pen, or Highlighter is chosen.
- `1` or `V` returns to Select.
- The visible application version remains `1.0.0.0`.

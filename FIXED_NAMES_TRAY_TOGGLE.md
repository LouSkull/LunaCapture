# Fixed screenshot names and persistent tray toggles

- Saved screenshots now always use the stable prefix `Screenshot`.
- Window titles and custom filename-prefix controls were removed.
- Region Save As suggestions also start with `Screenshot`.
- Changing Capture sound or Notifications from the tray no longer closes the tray menu.
- Toggle state updates immediately while the menu stays open.
- Capture commands, Open LunaShot, Screenshot folder, and Exit still close the tray menu normally.

# Region panel and hotkey update

Changes in this build:
- many new region-editor hotkeys: Ctrl+A, Ctrl+C, Ctrl+S, Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z, 1-6, B/G/T/Y/W, [ and ]
- right-click no longer cancels region or window capture
- only Esc cancels region and window selection sessions
- marker opacity buttons are shown only when Highlighter is selected
- color controls are shown only for drawing tools
- highlighter opacity is now applied through AlphaBlend instead of drawing fully opaque lines
- close/cancel toolbar button is removed from the visible toolbar

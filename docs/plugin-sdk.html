Luna Capture 1.0.0.0
LANGUAGE 1 · HOST API 5

Build native Luna Capture extensions.

LunaScript is a compact, event-driven language for commands, automation, capture and Replay control, guarded settings, audio setup, localization, and deeply customized native themes. The host parses every action, validates permissions before load, and never executes plugin machine code.

Architecture

Runtime model#

A plugin is data interpreted by Luna Capture, not a DLL or subprocess. It cannot call Win32, inspect frames, open arbitrary paths, access the network, or allocate native memory.

1

Parse

The entire UTF-8 file is tokenized and checked against Language 1 and the declared Host API requirement.

2

Validate

Unknown syntax, missing permissions, duplicate restricted properties, invalid ranges, and unsupported events reject the plugin.

3

Dispatch

Commands and handlers request bounded host operations through Luna's existing guarded UI paths.

Action blocks are dispatched synchronously, instruction by instruction, on the host UI thread. Capture, recording, and Replay instructions submit asynchronous requests: the block does not wait for a file or session transition to finish. Blocks are not transactions, have no rollback, and a later instruction may run before an earlier media request completes. Use completion and failure events for follow-up behavior.

Each top-level execution chain receives a 1024-instruction root budget. A command starts a fresh chain; one host event shares a chain across all of its handlers; one due-timer polling batch shares a chain across every selected timer handler. Every synchronous nested event spends the same remainder. Before a block runs, its complete size must fit the remaining root budget or the entire block is skipped. The budget resets only after the outermost dispatch or timer batch unwinds.

Errors do not terminate the hostA rejected or temporarily blocked operation reports through Luna and leaves future commands, timers, recording, and Replay behavior available. Other instructions in the block are not rolled back.
Get going

Quick start#

Save this complete file as any name ending in .luna. Any plugin using Host API 5 capabilities must state requires host_api 5;.

luna 1;

plugin "studio.acme.quick-capture" {
    name        "Quick Capture";
    version     "1.0.0";
    author      "Acme Studio";
    description "Captures the active display from Quick Panel.";
    requires host_api 5;

    permission capture;
    permission notifications;

    command "capture-now" {
        title "Capture now";
        description "Capture the display containing the foreground window.";
        icon "monitor";
        surface quick_panel;
        order 20;
        run {
            capture active;
            notify "Capture queued" "Luna will report when the image is saved.";
        }
    }
}
  1. Put the file under %LocalAppData%\Luna Capture\Plugins; nested folders are supported.
  2. Open Plugins, review the exact permission set, then enable the plugin.
  3. Run it from Manage or the requested Quick Panel surface.
Workflow

Install, disable & hot reload#

The managed directory is %LocalAppData%\Luna Capture\Plugins. Luna discovers up to 128 .luna files recursively. The directory contains only files you add.

  • Newly discovered plugins start disabled and require review.
  • Enabled state, permission approval, active theme ID, and active locale ID persist in plugins.ini; LunaScript cannot edit that file.
  • Luna checks source and declared theme-asset metadata about once per second, including while minimized.
  • A successful change is parsed and swapped in place. Commands, locale mappings, active theme visuals, and handlers refresh without restarting Luna.
  • Every timer schedule is cleared and restarted after a source or theme-asset reload.
  • A failed parse leaves Luna running and places the diagnostic on the plugin row in the Plugins page.
  • The manual Reload command immediately rescans added, removed, and changed files.
Language

File anatomy & manifest#

A file starts with exactly one language header and contains exactly one plugin block. Semicolons may be omitted only where the parser can finish a statement unambiguously; keeping them makes diagnostics clearer.

luna 1;
plugin "reverse.dns.style.id" {
    name "Required display name";
    version "1.0.0";
    author "Optional author";
    description "Optional short purpose";
    homepage "https://metadata-only.invalid";
    requires host_api 5;
    // permissions, theme, locale, commands, handlers
}

Trust boundary

Exact permission reapproval#

Luna remembers approval as a canonical permission fingerprint, not as a loose “trusted plugin” flag. The canonical form starts with v1, then appends each unique permission name in alphabetical order with | separators. A permission-free plugin fingerprints as v1. Thus declaration order and duplicate declarations do not change the fingerprint.

// These produce the same approval fingerprint:
permission notifications;
permission capture;

permission capture;
permission notifications;

// Canonical fingerprint:
v1|capture|notifications
  • Approvals are stored under [PermissionApprovals] in %LocalAppData%\Luna Capture\plugins.ini.
  • A missing fingerprint or any added/removed permission marks the plugin Review required.
  • If the plugin had been enabled, Luna fails closed: it disables and persists that disabled state until the user reviews and enables it again.
  • Explicit enable writes the current fingerprint. Disabling a plugin does not erase its approval.
  • The enable/review dialog uses host-owned, untranslated labels and canonical permission names. Active locale mappings cannot rename capabilities or spoof the approval prompt.
  • If an approval change disables the active theme or locale provider, Luna clears that selection safely.
  • Ordinary source edits and theme-asset changes hot-reload without new approval when the permission set is unchanged.
Language

Commands & action semantics#

A command is metadata plus exactly one non-empty run block. It is always available from the plugin's Manage menu and can opt into compact surfaces.

command "replay-control" {
    title "Save Replay";
    description "Request an export and open the Replay page.";
    icon "replay";
    surface quick_panel;
    surface tray;
    order 10;
    run {
        replay save_all;
        ui page replay;
    }
}
PropertyValidation
Command IDNon-empty, unique within the plugin, max 96 characters; letters, digits, dot, underscore, and hyphen only.
titleRequired and non-empty, max 128 characters.
descriptionOptional, max 256 characters.
iconOptional built-in hint, max 32 characters. Unknown hints fall back safely.
surfacequick_panel or tray. It may repeat; identical surfaces are deduplicated.
order0–1000, default 500. Lower values sort first.
runExactly one non-empty block, at most 128 instructions.

All command properties except surface may appear only once. A second title, order, icon, description, or run is rejected rather than silently overwriting the first. Quick Panel shows the first three eligible commands and the tray shows the first four, with deterministic ordering.

Built-in icon hints are monitor, displays, region, replay, record, folder, photo, video, save, and settings. Omission or an unknown name uses Luna's plugin glyph.

Request, then observereplay save_all; followed by open recordings; opens the folder immediately; it does not wait for export finalization. React to replay_saved when completion matters.

Automation

Timers & atomic dispatch budgets#

on timer every 900 {
    capture active;
    log "15-minute capture requested";
}
  • Intervals are whole seconds from 5 through 86400.
  • The first run is one full interval after enable or first scheduler sighting.
  • The scheduler is checked roughly once per second and also runs while Luna is minimized.
  • After firing, the next due time is now + interval. Missed intervals are not replayed, so app delays and tick granularity can cause drift.
  • Disable/re-enable and any source or theme-asset hot reload restart timer schedules.

Whole-handler selection budget

Each host-event dispatch has a 256-instruction total across matching handlers in deterministic source/plugin order. A handler runs only if its entire block fits the remaining selection budget. If the next handler would exceed it, dispatch stops before that handler; Luna never executes a partial prefix.

Due timers use the same 256-instruction atomic selection bound, but rotate the starting candidate across ticks. A timer that does not fit stays due, and the next scan begins with that candidate. This round-robin cursor prevents permanently starving handlers that sort later when many equal-period timers are due.

Root execution-chain budget

A separate 1024-instruction budget follows synchronous execution. A UI, tray, Quick Panel, or Manage command gets a fresh root; all handlers selected in one due-timer batch share one root; all handlers for one host event share one root. Synchronous nested events spend that same remainder. Every PluginExecution is admitted as a whole, and the budget resets only when the outermost command, event dispatch, or timer batch returns.

Predictable failure boundaryEach block is limited to 128 instructions, so a handler is always wholly executed or wholly skipped at both budget layers. Budget exhaustion never creates a half-applied block.
Theme Studio

Theme foundations#

A theme can redefine Luna's semantic palette, typography, geometry, global color grading, motion, layered procedural backdrops, and a safe plugin-local image. One plugin may declare one theme; one theme is active globally.

Declare permission theme;, then use theme "Display name" { … }. The optional appearance preset must be the first theme property, because it seeds the complete palette and later properties override that preset. Choose dark, light, or amoled; omitting it uses dark.

requires host_api 5;
permission theme;

theme "Midnight Glass" {
    appearance amoled;              // first, always

    background #05070B;
    background_secondary #11192A;
    surface #0B1019;
    surface_raised #121B2A;
    text #F5F8FF;
    muted #8E9BB2;
    accent #65A4FF;
    accent_secondary #B184FF;
    focus #9BC4FF;

    font_family "Segoe UI";
    font_scale 102;
    corner_scale 120;
    border_scale 110;
    motion_scale 70;

    backdrop mesh;
    backdrop_scope all;
    backdrop_color #559BFF;
    backdrop_color_secondary #A86BFF;
    backdrop_opacity 22;
    backdrop_scale 46;
    backdrop_thickness 1;
    backdrop_speed 35;
    backdrop_seed 4096;
    noise_opacity 3;
    vignette_color #000000;
    vignette_opacity 24;
}

command "use-theme" {
    title "Use Midnight Glass";
    run { theme activate; }
}

command "reset-theme" {
    title "Use Luna theme";
    run { theme reset; }
}

theme activate;

Activates the theme declared by the calling plugin. It cannot select another plugin's theme.

theme reset;

Restores Luna's built-in global theme. Both instructions require theme.

The plugin's Manage menu also exposes Activate/Reset without requiring a command. The API 5 actions let authors build the same choice into a command or handler.

Property uniquenessEvery theme property may appear only once. Unknown properties, wrong value kinds, duplicates, and out-of-range values reject the file with a parser diagnostic.

Image sandbox and decode limits

  • The compressed file may not exceed 16 MiB.
  • Canonical path resolution must remain beneath the plugin directory. Absolute paths, .. escape, and symlink/reparse escapes are blocked.

Coverage, layer order & authoring rules#

Backdrop scope

ScopePainted surfaces
mainOnly the main Luna application canvas.
panelsNon-main Luna surfaces: Quick Panel, custom tray menu, overlay, app-owned dialogs, and region-editor chrome.
allBoth classes.

Deterministic layer order

  1. Opaque semantic surface/base gradient.
  2. Decoded background image with its fit, grading, tint, and opacity.
  3. The chosen procedural backdrop pattern.
  4. Supplemental noise when configured and not already supplied by backdrop noise.
  5. Vignette.
  6. Normal Luna controls, text, icons, status, and content.

The theme applies to Luna-painted pixels: main window, Quick Panel, custom tray menu, Luna overlay, app-owned dialogs, and editor chrome. Windows Explorer, file pickers, the taskbar, protected/system UI, and OS-owned notification surfaces remain controlled by Windows. Screenshot pixels, video frames, live previews, device names, filenames, and annotation content are never color-remapped by a theme.

Theme author checklist

  • Put appearance first, then override semantic roles.
  • Test main, panels, overlays, dialogs, editor chrome, hover, pressed, selected, disabled, and keyboard focus states.
  • Test with motion_scale 0 and avoid relying on animation to communicate state.
  • Keep text legible over both the image and procedural layers; reduce opacity or add vignette when needed.
  • Use stable relative asset paths. Asset replacement hot-reloads without restarting Luna.
  • Keep important visuals away from image edges if using cover, which can crop.
Fast iterationSave the source or replace its image asset, wait about one second, and inspect every Luna-owned surface. Parser and asset failures appear on the Plugins page; the previous host remains alive.
Host API

Localization packs#

One plugin may declare one non-empty locale. Mappings replace exact Luna-owned UI strings or safe positional templates. They do not rewrite filenames, device names, captured content, user input, or text painted by Windows.

requires host_api 5;
permission localization;

locale "ru-RU" {
    "Home" = "Главная";
    "Capture" = "Снимок";
    "Saved {0}" = "Сохранено: {0}";
}

command "locale-on" {
    title "Activate language";
    run { locale activate; }
}

command "locale-reset" {
    title "Reset language";
    run { locale reset; }
}
  • At most 1024 mappings; source and replacement are each limited to 512 characters.
  • Sources must be unique and both sides must be non-empty.
  • Supported placeholders are {0} through {9}. A replacement may use only placeholders present in its source.
  • Source placeholders must be separated by literal text; adjacent placeholders are rejected.
  • locale activate; selects the calling plugin's locale; locale reset; restores Luna's built-in strings.
  • notify title/detail strings pass through the active locale just like other Luna-owned interface text. Add exact or positional mappings when plugin-authored notifications should be translated.

The plugin's Manage menu always offers activation/reset for a declared locale. The action instructions provide the same transition to API 5 commands and handlers.

Capture-loss behavior

A temporary fullscreen transition, mode switch, Alt+Tab, or display-source loss does not automatically terminate an active recording or Replay session. Luna keeps timestamps and audio moving, paints a dark recovery card into the existing video timeline, retries capture about every 250 ms, and returns to live frames when the source reconnects. Handlers can observe recording_recovering, recording_recovered, replay_recovering, and replay_recovered. A genuinely terminal writer failure still emits the corresponding *_failed event.

Screenshot failure emits capture_failed without disabling the plugin or future scheduled attempts. Region and window capture remain single-flight until their editor flow closes, preventing overlapping selection surfaces and duplicated frozen frames.

Microphone mixer & bounded DSP#

Audio instructions require permission audio;. A target is an exact friendly device name, a stable Windows endpoint ID, or "default". Target strings are limited to 256 characters. Any operation except remove_microphone adds a missing valid endpoint automatically when a mixer slot is available.

permission audio;

audio add_microphone "default";
audio microphone_enabled "default" on;
audio microphone_gain "default" 112;
audio noise_suppression "default" 65;
audio noise_gate "default" 48;

// Later, if desired:
audio remove_microphone "default";
OperationValueBehavior
add_microphonetarget onlyAdds/enables one enumerated endpoint.

The native mixer has at most four configured microphone slots. Endpoint topology, enable state, gain, and filters are session-locked while recording or Replay is live. A missing device, full mixer, or live lock reports the blocked operation and leaves the rest of the handler nontransactional.

Compact grammar#

file          := "luna" "1" ";"? plugin
plugin        := "plugin" string "{" member* "}"
member        := metadata | requirement | permission | theme | locale | command | event
metadata      := ("name"|"version"|"author"|"description"|"homepage") "="? string ";"?
requirement   := "requires" "host_api" "="? integer ";"?
permission    := "permission" permissionName ";"?

theme         := "theme" string "{" themeProperty* "}"
themeProperty := identifier "="? (color | integer | string | identifier | toggle) ";"?
locale        := "locale" string "{" (string "="? string ";"?)+ "}"

command       := "command" string "{" commandMember* "}"
commandMember := ("title"|"description"|"icon") string ";"?
               | "surface" ("quick_panel"|"tray") ";"?
               | "order" integer ";"?
               | "run" actionBlock
event         := "on" eventName actionBlock
               | "on" "timer" "every" integer actionBlock
actionBlock   := "{" instruction* "}"

instruction   := "notify" string string ";"?
               | "log" string ";"?
               | "capture" ("active"|"all"|"region"|"window") ";"?
               | "capture" "monitor" integer ";"?
               | "recording" ("start"|"stop"|"toggle") ";"?
               | "replay" ("start"|"stop"|"toggle"|"save_all") ";"?
               | "replay" "save_monitor" integer ";"?
               | "setting" settingName (identifier | integer | toggle) ";"?
               | "audio" audioOperation string (integer | toggle)? ";"?
               | "open" ("screenshots"|"recordings"|"plugins"|"replay_cache"|"logs") ";"?
               | "ui" ("show"|"hide"|"toggle") ";"?
               | "ui" "page" pageName ";"?
               | "quick_panel" ("show"|"hide"|"toggle") ";"?
               | ("theme"|"locale") ("activate"|"reset") ";"?

Sandbox & security model#

LunaScript deliberately excludes general-purpose execution. There is no DLL loading, native code, PowerShell, plugin-selected process launch or shell arguments, arbitrary filesystem access, registry access, network access, raw frame/audio access, memory access, injection, hooks, variables, user-defined loops, or sleeps.

  • Permissions are statically checked for every instruction before load and approved as an exact canonical set.
  • Capability review is rendered from immutable host strings with localization bypass, so a plugin locale cannot relabel its requested access.
  • Plugin identities are matched case-insensitively across duplicate detection, command dispatch, active theme/locale ownership, and persisted host state.
  • Settings, media, UI, and audio actions pass through the same range checks and active-session guards as Luna's own interface.
  • The only external process path is host-controlled Explorer opening one of five fixed Luna-owned locations.
  • Theme files are constrained to a canonical plugin-local path, fixed formats, and bounded compressed/decoded sizes.
  • Commands and handlers have 128-instruction block, 256-instruction selection, 1024-instruction root-chain, recursion, source-size, and collection limits; every block is admitted atomically.
  • Plugin source cannot bypass Windows protected surfaces, secure desktops, exclusive-content policy, or OS-owned UI.
Readability is part of trustKeep permission declarations next to the feature that needs them, use explicit start/stop actions in automation, and explain every visible command in its title and description.

Diagnostics & troubleshooting#

SymptomWhat to inspect
Red plugin row after saveOpen Plugins and read the parser diagnostic with source line/column. Check unknown tokens, required fields, duplicate properties, range limits, and matching braces.
“Requires Host API …”This build supports Host API 5. A missing declaration is treated as legacy API 4, and a lower declaration cannot use API 5-only syntax. Add requires host_api 5;; a higher number needs a newer host.
“Instruction requires permission …”Add exactly the named declaration. The permission fingerprint will change and the user must review it again.
Review required after editThe unique permission set changed. Reordering declarations alone does not trigger this state.
Command will not loadVerify non-empty ID/title, one non-empty run, unique non-surface properties, 0–1000 order, and no more than 128 instructions.
Setting or microphone command blockedRecording or Replay may hold the session lock, an endpoint may be missing, or all four slots may be occupied. Stop the live session and retry.
Timer seems lateTimers use an approximate one-second host tick, schedule the next fire from the actual run time, do not catch up missed intervals, and restart after reload.
Second event handler did not runThe prior matching handlers may have consumed the 256-instruction total. The skipped handler is not partially executed.
Nested or later timer handler was skippedThe command/event chain, or earlier selected timers and their nested events in the same batch, may have consumed the shared 1024-instruction root budget. Luna logs the atomic rejection; the skipped block never runs as a prefix.

Theme does not affect Explorer/system UIExpected: themes cover only Luna-painted surfaces. OS-owned pixels remain under Windows.

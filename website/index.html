What's inside

One native app, six workflows.

Everything below runs from a single, self-contained executable — no installer service, no background updater, no bundled runtime.

●Screen recording studio

H.264, HEVC, or AV1 MP4 recording with FPS presets from 24–240, automatic foreground-game monitor selection, uninterrupted recovery across fullscreen transitions and GPU resets, and hardware Media Foundation encoders when available.

♪Audio mixer

System loopback, per-application audio, and up to four microphones mixed live to 48 kHz stereo AAC with independent 0–200% gain, a soft limiter, and persisted device slots for USB mics.

↺Instant replay / rollback

A rolling encoded buffer — not raw frames in RAM — across up to three monitors at once. One hotkey saves everything that just happened; the buffer resumes automatically after a restart if it was left on.

◈LunaScript plugins

A sandboxed, permission-fingerprinted native extension platform — commands, timers, events, guarded settings, and a full Theme Studio. No DLLs, no network access, no filesystem access. Full SDK →

▤Settings & startup

Every setting saves itself to a single portable settings file — copy it to another machine and the whole setup travels with it. Plus "Start with Windows" and direct-to-tray launch.

◇Native interface

Every icon, card, toggle, and panel is anti-aliased GDI+ — no WebView, no Chromium, no layout thrash. A dark rounded chrome shared across the main window, tray, overlay, and region editor.

Default shortcuts

Every binding below is rebindable in-app and routed through three deduplicated input paths (Raw Input, a low-level keyboard fallback, and RegisterHotKey) so it keeps working inside exclusive-fullscreen games.

Build from source

The official binary lives in the repository below. To build it yourself:

install_and_run.bat

This checks for CMake and the MSVC x64 toolchain, builds a static-runtime Release executable, runs the core tests, and starts dist\LunaCapture.exe.

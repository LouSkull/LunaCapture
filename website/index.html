Small, focused screenshots.

Luna Capture is a fixed-size native Windows screenshot desk. It captures on demand, then releases hardware while idle. No video recorder, replay buffer, audio mixer, plugins, browser runtime, or telemetry.

Compact by design

Borderless fixed-size window, custom minimise and close controls, and a top bar that drags naturally.

Clean output

PNG or JPEG, ordered millisecond filenames, optional sound, and a lightweight overlay confirmation.

Native and idle

DXGI, WIC, and Win32 only. Capture hardware is not kept alive between requests.

Updates

Version checks stay under your control.

Settings offers a manual check against the official GitHub releases page. Luna Capture never runs a hidden updater.
